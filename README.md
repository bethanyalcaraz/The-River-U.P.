# The River U.P.

Coming-soon landing page for The River U.P., a gospel-centered church plant
launching in Rapid River, Michigan (Upper Peninsula) in September 2027.

## Pages

- `index.html` — single-page site: hero, vision, prayer points, serving
  opportunities (Pray / Give), and a sign-up-to-serve contact form

## Adding photos

There are no photos wired in yet. To add one:

1. Drop the image file in `images/` (e.g. `images/hero.jpg`)
2. Reference it from `index.html` or `css/style.css`

## Running locally

This is a static site with no build step. Open `index.html` directly in a
browser, or serve the folder with any static file server, e.g.:

```
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
